
# 🔐 Login & Registration System (Java Swing)

A simple desktop application demonstrating a user **Login** and **Registration** interface built using **Java Swing**.

**⚠️ Note:** This project focuses on **UI design** and basic **event handling**. It does **not** currently use an external database (SQL, etc.). Data is handled temporarily within the application runtime (or uses hardcoded credentials).


## ✨ Features

* **User Interface:** Clean and simple GUI using `JFrame`, `JPanel`, and custom styling.
* **Login Screen:** Accepts username and password inputs.
* **Registration Screen:** Allows new users to "register" (simulated).
* **Navigation:** Smooth transition between Login and Sign-up windows.
* **Input Validation:** Checks if fields are empty (Basic validation).

---

## 🛠️ Technologies Used

* **Language:** Java
* **GUI Library:** Swing (JFrame, JButton, JTextField, etc.) & AWT
* **IDE:** [Eclipse / IntelliJ IDEA / NetBeans] ---

## 🚀 Getting Started

Follow these instructions to run the project on your local machine.

### Prerequisites

* Java Development Kit (JDK) 8 or higher installed.

### Installation & Run

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/KULLANICI_ADIN/PROJE_ADIN.git](https://github.com/KULLANICI_ADIN/PROJE_ADIN.git)
    ```
2.  **Open the project:**
    Open the project folder in your preferred Java IDE (IntelliJ, Eclipse, etc.).
3.  **Run the application:**
    Locate the `Main.java` (or your main class file) and run it.
